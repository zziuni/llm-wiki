## 핵심 요약

### SaaS 정의
클라우드 컴퓨팅 서비스 모델로, 공급자가 인터넷을 통해 완성된 애플리케이션을 제공하며, 기반 인프라·미들웨어·소프트웨어 유지보수를 모두 관리한다. 사용자는 웹 브라우저로 접근하여 소프트웨어를 사용만 한다.

### 핵심 특성 6가지
1. **구독 기반 과금** — 영구 라이선스 대신 월/년 단위 구독료
2. **멀티테넌시** — 단일 인스턴스가 복수 고객을 서비스
3. **자동 업데이트** — 벤더가 보안 패치·기능 업데이트 관리
4. **웹 기반 접근** — 설치 없이 브라우저로 즉시 사용
5. **확장성** — 수요에 따라 구독 수준 조정
6. **API 기반 통합** — 타사 시스템과의 연동 지원

### 클라우드 서비스 모델 스택

| 관리 영역 | On-Prem | IaaS | PaaS | SaaS |
|-----------|---------|------|------|------|
| 네트워킹/스토리지 | 사용자 | 제공자 | 제공자 | 제공자 |
| 가상화 | 사용자 | 제공자 | 제공자 | 제공자 |
| OS | 사용자 | 사용자 | 제공자 | 제공자 |
| 미들웨어 | 사용자 | 사용자 | 제공자 | 제공자 |
| 애플리케이션 | 사용자 | 사용자 | 사용자 | 제공자 |
| 데이터 | 사용자 | 사용자 | 사용자 | 사용자 |

> 위로 갈수록 제공자 관리 범위 확대. SaaS는 데이터만 사용자가 관리.

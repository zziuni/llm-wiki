# /autoresearch — 자율 연구 루프

주제에 대해 자율적으로 웹 검색 → 수집 → 합성을 반복하여 위키를 확장한다.

> **경로 기준**: 모든 `raw/`, `wiki/` 경로는 `$LLM_WIKI_ROOT` 기준. 미설정 시 CWD. 상세는 wiki skill의 "경로 규칙" 참조.

## 인자

- `주제`: 연구할 주제

## 워크플로우

### 각 라운드:
1. **현황 파악**: 위키에서 주제 관련 기존 지식 확인
2. **공백(knowledge gap) 식별**: 아직 답이 없는 질문, 부족한 영역 파악
3. **웹 검색**: 공백을 채울 소스 탐색
4. **수집**: 발견한 소스를 ingest 워크플로우로 수집
5. **합성 갱신**: overview 또는 관련 개념 페이지 갱신
6. **다음 라운드 판단**: 새로운 공백이 있으면 반복

### 안전장치
- 최대 라운드: 5 (기본값)
- 각 라운드 후 사용자에게 진행 상황 리포트
- 사용자가 중단하거나 방향 전환 가능
- 수집한 소스 목록 제시

### 완료 시
- 최종 리포트: 수집한 소스 수, 생성/갱신된 페이지, 남은 공백
- `wiki/log.md`에 기록: `## [YYYY-MM-DD] autoresearch | 주제 (N라운드)`

# /save — 대화를 위키에 저장

현재 대화에서 가치 있는 내용을 위키 노트로 저장한다.

> **경로 기준**: 모든 `raw/`, `wiki/` 경로는 `$LLM_WIKI_ROOT` 기준. **미설정 시 동작 중단** — wiki skill의 "가드 절차" 참조.

## 인자

- `이름` (선택): 저장할 페이지 이름. 생략 시 대화 내용에서 자동 추론.

## 워크플로우

1. **대화 분석**: 현재 대화에서 위키에 보존할 가치가 있는 내용 식별
   - 새로운 발견, 분석, 비교, 의사결정

2. **페이지 유형 결정**:
   - 분석/비교 → `wiki/analyses/`
   - 새 개념 발견 → `wiki/concepts/`
   - 새 엔티티 발견 → `wiki/entities/`

3. **페이지 생성**: frontmatter 포함, 적절한 위치에 생성

4. **교차참조**: 관련 기존 페이지에 `[[wikilink]]` 추가

5. **인덱스 갱신**: `wiki/index.md` 갱신

6. **로깅**: `wiki/log.md`에 기록: `## [YYYY-MM-DD] save | 페이지 이름`

# Schema Migration v2 — Company Context Boundary

## 목적

일반 기술 지식과 특정 회사에서만 유효한 업무 컨텍스트를 구조적으로 분리할 수 있도록 `wiki/company/` 경계를 추가한다.

## 절차

1. `wiki-root.sh --ensure-dir wiki/company/`로 상위 디렉터리를 생성한다.
2. `wiki/company/index.md`가 없으면 `type: overview`, summary, created, updated, `status: active` frontmatter와 빈 Companies 목록을 가진 진입 문서를 생성한다.
3. vault root의 `AGENTS.md`에 이미 회사별 구조가 정의되어 있으면 그 구조를 보존한다.
4. 기존 `wiki/concepts/`, `wiki/analyses/`, `wiki/sources/` 문서는 자동 이동하지 않는다.
5. 기존 회사 관련 문서는 사용자가 승인한 별도 정리 작업에서 점진적으로 이동한다.

## 완료 조건

- `wiki/company/`와 `wiki/company/index.md`가 존재한다.
- 기존 페이지와 wikilink가 변경되지 않았다.
- `.llm-wiki-meta.json`의 `schemaVersion`이 2로 갱신된다.

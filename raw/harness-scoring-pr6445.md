## 파일 1: .github/workflows/harness-scoring.yml

```yaml
name: Harness Scoring

on:
  pull_request:
    types:
      - opened
      - synchronize
      - edited
      - closed

jobs:
  submit-normalized-ingress:
    uses: musinsa/harness-engineering-scoring-system/.github/workflows/harness-scoring-ingress.yml@main
    secrets: inherit
```

### 분석
- PR 이벤트(열림, 동기화, 편집, 닫힘) 시 트리거
- 중앙 `musinsa/harness-engineering-scoring-system` 레포의 reusable workflow 호출
- `secrets: inherit`로 조직 secrets 자동 전달
- Job 이름 `submit-normalized-ingress`는 정규화된 PR 데이터를 중앙 시스템에 제출하는 역할 시사
